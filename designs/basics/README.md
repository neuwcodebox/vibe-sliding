# Vibe Sliding Basics

This is the project-owned starter collection. Each Markdown file listed in
[`index.json`](./index.json) under `themes/` is a peer, selectable theme leaf;
this README is collection metadata and is not selectable.

Read one selected theme completely before authoring a new deck or broad
redesign. Each file is a reusable visual contract: it defines hierarchy,
typography, color, composition, density, evidence, motion, and CJK rules. It
does not define a deck outline or a hidden global theme.

Add a new file under `themes/` and its metadata to `index.json` only for a
direction that should remain useful across future decks. Otherwise retain the
current theme for a narrow revision, or select a theme leaf from another
collection in [`../README.md`](../README.md).
