# Vibe Sliding Basics

This is the project-owned starter collection. Each Markdown file in the table
below is a peer, selectable theme leaf; this README is collection metadata and
is not selectable.

| Theme | Best fit | Character |
| --- | --- | --- |
| [`minimal-dark.md`](minimal-dark.md) | Focused technical explainers and concise internal updates | Sparse, quiet, and precise |
| [`executive-clean.md`](executive-clean.md) | Decision memos, status reports, and management reviews | Clear, restrained, and scan-friendly |
| [`technical-grid.md`](technical-grid.md) | Architecture, APIs, infrastructure, and workflows | Structured, analytical, and implementation-aware |
| [`startup-pitch.md`](startup-pitch.md) | Product vision, launches, demos, and energetic storytelling | Bold, optimistic, and product-led |

Read one selected theme completely before authoring a new deck or broad
redesign. Each file is a reusable visual contract: it defines hierarchy,
typography, color, composition, density, evidence, motion, and CJK rules. It
does not define a deck outline or a hidden global theme.

Add a new file here only for a direction that should remain useful across future
decks. Otherwise retain the current theme for a narrow revision, or select a
theme leaf from another collection in [`../README.md`](../README.md).
