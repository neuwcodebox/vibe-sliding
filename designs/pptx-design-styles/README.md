# PPTX Design Styles

30개의 현대 프레젠테이션 스타일을 탐색하기 위한, 원본에 근거한 분할형 참조
컬렉션입니다. 스타일 하나가 이 컬렉션의 테마 리프입니다.

먼저 [`index.json`](./index.json)에서 스타일 이름과 파일을 찾고, 필요한 단일
스타일만 [`styles/`](./styles/)에서 읽으세요. 인덱스에는 각 스타일의 `mood`와
`best_for`도 있어 빠른 후보 선별에 쓸 수 있습니다. 각 섹션 파일에는 배경, 색상,
글꼴, 레이아웃, 시그니처 요소, 피해야 할 사항이 들어 있습니다. 원문 전체는 이
저장소에 보관하지 않습니다.

원본의 글꼴 지침은 Vibe Sliding의 Inter 및 Noto Sans KR 스택으로 대체하고,
고정 16:9 무대와 한국어 가독성에 맞게 해석합니다. 원본의 스타일은 출발점이며,
개별 슬라이드는 하나의 선택된 스타일만 시각 문법으로 사용해야 합니다.

출처, 포함 범위, 갱신 방법은 [`UPSTREAM.md`](./UPSTREAM.md)를, 라이선스 선언은
[`LICENSE`](./LICENSE)를 참조하세요.
